## Conventions

| Topic | Rule |
| --- | --- |
| Base path | `/api/v1`; breaking changes go to `/api/v2` |
| Auth | `Authorization: Bearer {memberId}.{writeToken}`; server compares SHA-256 of the token with `timingSafeEqual` |
| Idempotency | `Idempotency-Key` on every write; stored 24 h per member; a repeat returns the stored response with header `Idempotent-Replay: true` |
| Rate limits | 30 writes per minute per member, 300 per minute per gathering, 20 drafts per minute per IP; 429 with `Retry-After` |
| Errors | `{code, message}`; `code` from a fixed list of 25; phones map codes to copy deck strings, never show `message` |
| Validation | zod schemas generated by hand from the contract live in `packages/shared/src/api.ts`; bodies outside the schema get 400 `bad_request` with no echo of the input |
| Time | UTC ISO 8601 with milliseconds; every view carries `server_time` |
| Sealed fields | `*_ct` and `sealed`: base64url ciphertext; size caps in the schema |
| Caching | Views: `ETag` = version, `Cache-Control: no-store`; photo ciphertext: `private, max-age=3600, immutable` |
| CORS | Same origin only; no `Access-Control-Allow-Origin` |
| Body limits | JSON 64 KB; photo 1.5 MB |

## Endpoints by job

| Job | Endpoint | Requirement |
| --- | --- | --- |
| Health, config, audit | `GET /health`, `GET /config`, `GET /audit` | SRS-WEB-2 |
| Create and join a group | `POST /groups`, `POST /groups/{g}/members`, `GET /groups/{g}` | SRS-ID-1 to 5 |
| Rename, forget | `PATCH`, `DELETE /groups/{g}/members/{m}` | SRS-ID-6, ADR-0015 |
| Send | `POST /groups/{g}/gatherings`, `PUT /gatherings/{id}/photo` | SRS-CRE-6, -7, SRS-PLAN-1 |
| Read and follow | `GET /gatherings/{id}`, `/photo`, `/events` | SRS-RES-1, SRS-SOL-3 |
| Answer | `GET`, `PUT`, `DELETE /gatherings/{id}/me`, `PUT /me/checks` | SRS-RES-3, -6, SRS-COND-6, SRS-ACC-3 |
| Text yes | `POST /gatherings/{id}/text-yes` | SRS-CH-6 |
| Plans | `POST /gatherings/{id}/fade` | SRS-PLAN-7 |
| Lit | `POST /arrivals`, `PUT`, `GET`, `DELETE /live-location`, `POST /done`, `POST /cancel` | SRS-LIT-3, -4, SRS-CMP-6, SRS-ST-4 |
| Places | `POST`, `GET /groups/{g}/sparks`, `GET`, `PUT /groups/{g}/hotspots` | SRS-SPK-1, -2, SRS-HOT-1, -2 |
| Push | `PUT`, `DELETE /groups/{g}/push-subscriptions` | SRS-IF-3 |
| AI | `POST /drafts`, `POST /drafts/ladder` | SRS-AI-1, SRS-PLAN-2 |
| Telegram | `POST /groups/{g}/telegram-link`, `POST /gatherings/{id}/telegram-bind`, `PUT /gatherings/{id}/telegram-photo`, `POST /telegram/webhook` | SRS-CH-1 to 4 |

Pages that are not API: `GET /g/{id}` (app HTML with safe Open Graph tags, ADR-0017), `GET /check` (capability page), static app files.
