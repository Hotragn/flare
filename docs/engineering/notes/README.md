# Work package notes

One file per work package, `{WP}.md` (for example `CE1.md`), written when the package merges: what was built, the numbers that prove it, decisions taken inside the package, and anything the next person must know. Template:

```markdown
# {WP}: {title}
Owner: {specialist}. Merged: {commit}. Requirements: {ids}.
## Built
## Proof (commands and numbers)
## Decisions
## For the next person
```
