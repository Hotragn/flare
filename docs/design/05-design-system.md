## 2. Components

Every component exists in code with all states; the catalog renders each in light, dark and sun.

## 3. Rules

1. One primary button per screen. Secondary actions are text buttons.
2. Use role variables, never raw hex, in product code.
3. State is shown by the flame's shape first and color second.
4. Outdoor screens (Lit, compass, Ember, arrival, host waiting) use `data-sun`.
5. Motion uses tokens only, so reduced motion turns it off everywhere.
6. No new component without all states (empty, loading, error, offline, success where relevant) in the catalog.
